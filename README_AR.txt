تطبيق كريم الشرعبي - مشروع Android WebView

- اسم التطبيق: كريم الشرعبي
- شاشة التطبيق ومحتواه من ملف HTML الحالي كما هو.
- الاتصال بالإنترنت مفعل حتى يعمل اتصال Supabase.
- بناء APK يتم عبر GitHub Actions.

بعد رفع ملفات هذا المجلد إلى مستودع GitHub باسم Karim-Alsharabi، افتح تبويب Actions ثم اختر Build Karim Alsharabi APK ثم Run workflow. بعد انتهاء البناء، افتح نتيجة التشغيل وحمّل Artifact باسم Karim-Alsharabi-APK، ثم فك ضغطه لتحصل على app-debug.apk.
